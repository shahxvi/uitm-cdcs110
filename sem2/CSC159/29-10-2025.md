# Sign-and-Magnitude Representation

Positive uses zero
Negative uses one

1 byte = 8 bit
1 byte = 00000000

The first at the front = Sign
The rest at the back = Magnitude

Example:
31 = 11111_2
+ 31 = 00011111
- 31 = 10011111

# The IEEE Floating Point Representation

IEEE = Base 16
IEEE short real: 32 (Exponent system = excess 127)

Steps:
1. Convert into binary
2. Put into 1.xxx(2^y) format
        - 1001.1111_2
        - 1.0011111x2^3
        - Jump to left = Positive
        - Jump to right = Negative
3. Find the sign
4. Find biased exponent
5. Find significand / mantissa
6. Put into IEEE format
6. Convert into hexadecimal
