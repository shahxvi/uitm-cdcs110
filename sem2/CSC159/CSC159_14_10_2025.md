MOV Instructions - Legal

| Mnemonic | Destination Operand | Source Operand | Example                 |
| -------- | ------------------- | -------------- | ----------------------- |
|          | Register            | Immediate      | MOV AX, 10h             |
|          | Memory              | Immediate      | MOV sum, 14             |
|   MOV    | Register            | Register       | MOV AX, BX / MOV BL, CL |
|          | Memory              | Register       | MOV total, AX           |
|          | Register            | Memory         | MOV AX, Z               |

MOV Instructions - Illegal

| Mnemonic | Destination Operand | Source Operand | Why it's illegal                                                                       |
| -------- | ------------------- | -------------- | -------------------------------------------------------------------------------------- |
| MOV      | word_1              | word_2         | Both operands are memory locations; not a valid move                                   |
| MOV      | DS                  | 1000h          | DS is Data Segment, cannot directly move an immediate value into it                    |
| MOV      | IP                  | AX             | Moving data to the Instruction Pointer (IP) is not allowed; it's a protected register  |
| MOV      | AL                  | BX             | Size Mismatch; AL is 8-bits, BX is 16-bits, so they can't be moved directly            |
| MOV      | 1000h               | AX             | You cannot copy something into a number (immediate value cannot directly overwrite AX) |

Addressing Modes
- The term addressing mods refers to the way in which the operand of an instruction is specified. The addresing mode specified a rule for interpreting or modifying the address field of the instruction before the oprand is actually executed
- The X86 CPU family (8088, 8086, 80286, 80386, 80486, Pentium, Pentium Pro, Pentium II, III, IV) support 5 types of addressing mode

The different ways in which a source operand is denoted in an instruction is known as addressing modes

| Mnemonic | Destination Operand | Source Operand | Addressing Mode   |
| -------- | ------------------- | -------------- | ----------------- |
| MOV      | AX                  | BX             | Register          |
| MOV      | AX                  | 25h            | Immediate         |
| MOV      | AX                  | `[E14h]`       | Direct            |
| MOV      | AX                  | `[BX]`         | Register Deferred |
| MOV      | AX                  | `[BX+5]`       | Base              |
